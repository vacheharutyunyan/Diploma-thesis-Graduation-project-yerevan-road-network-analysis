# Երևանի ճանապարհային ցանցի վերլուծություն և դինամիկ երթուղիների օպտիմալացում

Գրաֆների տեսության և ճանապարհային խցանումների վերլուծության միջոցով Երևանի ճանապարհային ցանցում դինամիկ երթուղիների օպտիմալացման համակարգի մշակում՝ օգտագործելով կարճագույն ճանապարհի որոնման ալգորիթմները:

## Նախագծի նկարագրություն
Այս նախագծի նպատակն է մոդելավորել Երևանի Կենտրոն վարչական շրջանի ճանապարհային ցանցը որպես ուղղորդված, կշռված գրաֆ (OpenStreetMap-ի տվյալներով) և ուսումնասիրել Դեյկստրայի և A* ալգորիթմների արդյունավետությունը ծանրաբեռնված երթևեկության պայմաններում օպտիմալ երթուղիներ կառուցելիս:

Ամբողջական դիպլոմային աշխատանքի տեքստը կարող եք կարդալ այստեղ՝ [Դիպլոմային աշխատանք (docs/Diploma_Thesis.md)](docs/diploma_Thesis.md)։

##  Ռեպոզիտորիայի կառուցվածքը
* `data/` - Ելակետային տվյալներ
* `notebooks/` - Jupyter տետրեր տվյալների վերլուծության և մոդելավորման համար
* `src/` - Հիմնական Python սկրիպտներ
* `docs/` - Փաստաթղթեր և դիպլոմային աշխատանքի ամբողջական տեքստը
* `results/` - Գեներացված քարտեզներ և գրաֆիկներ

##  Հիմնական արդյունքներ

Նախագծում համեմատվել են **ֆիզիկապես ամենակարճ** և խցանումները հաշվի առնող **ամենաարագ** երթուղիները: 

![Երթուղիների համեմատություն](results/map_routes.png)

Արդյունքները ցույց են տալիս, որ A* ալգորիթմով հաշվարկված ամենաարագ երթուղին, թեև երկարությամբ զիջում է ամենակարճ երթուղուն 24.9%-ով, սակայն թույլ է տալիս խնայել ճանապարհածախսի ժամանակը 28.7%-ով՝ շրջանցելով հիմնական խցանված հանգույցները:
