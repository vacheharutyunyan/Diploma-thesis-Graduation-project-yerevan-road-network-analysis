# Երևանի ճանապարհային ցանցի վերլուծություն և դինամիկ երթուղիների օպտիմալացում

Այս նախագիծը միավորում է կուրսային աշխատանքի և ավարտական թեզի փուլերը՝ Երևանի ճանապարհային ցանցում երթուղիների օպտիմալացման համար։

## Նպատակ
Կառուցել Երևանի ճանապարհային ցանցի գրաֆային մոդելը, համեմատել Dijkstra և A* ալգորիթմները, այնուհետև իրական երթևեկության տվյալների հիման վրա զարգացնել խցանումների կանխատեսման և դինամիկ երթուղավորման համակարգ։

## Աշխատանքի փուլերը
1. Ճանապարհային ցանցի ստացում և գրաֆի կառուցում՝ OSMnx / NetworkX։
2. Dijkstra և A* ալգորիթմների իրականացում և համեմատություն։
3. Իրական երթևեկության տվյալների հավաքագրում և մշակում։
4. Ճանապարհային հատվածների անցման ժամանակի գնահատում։
5. GNN մոդելի մշակում՝ խցանումների տարածաժամանակային կանխատեսման համար։
6. Կանխատեսված արժեքներով դինամիկ երթուղու օպտիմալացում։

## Կարևոր սկզբունք
Խցանումների տվյալները պետք է հիմնվեն դիտարկումների վրա (օրինակ՝ քարտեզների սքրինշոթներ կամ հասանելի իրական տվյալներ)։ Չդիտարկված հատվածները չեն նշվում որպես ազատ երթևեկությամբ։ Պատահական խցանումներ չեն գեներացվում։

## Կառուցվածք
- `data/` — հում և մշակված տվյալներ
- `docs/` — նախագծի նկարագրություն, մեթոդաբանություն և աղբյուրներ
- `notebooks/` — հետազոտական Jupyter notebook-ներ
- `src/` — ծրագրային իրականացում
- `results/` — գրաֆիկներ, աղյուսակներ և փորձերի արդյունքներ
- `tests/` — թեստեր

Տեղադրման համար՝ `pip install -r requirements.txt`։
