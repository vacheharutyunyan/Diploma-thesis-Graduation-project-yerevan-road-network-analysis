# Նախագծի նկարագրություն

Նախագծի նպատակն է մշակել Երևանի ճանապարհային ցանցում դինամիկ երթուղիների օպտիմալացման համակարգ։

Կուրսային աշխատանքի փուլում կառուցվում է ճանապարհային գրաֆը և նույն պայմաններում համեմատվում են Dijkstra և A* ալգորիթմները։ Ավարտական աշխատանքի փուլում ավելացվում է երթևեկության տվյալների մշակում, GNN մոդելով խցանումների կանխատեսում և կանխատեսված ճանապարհային կշիռներով դինամիկ երթուղավորում։

GNN-ը գնահատում է ճանապարհային հատվածների ապագա վիճակը կամ անցման ժամանակը, իսկ Dijkstra/A* ալգորիթմներն օգտագործում են այդ կշիռները՝ երթուղին գտնելու համար։
