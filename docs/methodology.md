# Մեթոդաբանություն

1. Երևանի ճանապարհային ցանցի ներբեռնում և գրաֆի կառուցում OSMnx/NetworkX գործիքներով։
2. Ճանապարհային հատվածների երկարության և ելակետային անցման ժամանակի սահմանում։
3. Dijkstra և A* ալգորիթմների իրականացում։
4. Ալգորիթմների համեմատություն նույն սկզբնակետով, վերջնակետով և կշիռներով՝ երթուղու արժեք, կատարման ժամանակ և այցելված հանգույցներ։
5. Իրական երթևեկության դիտարկումների հավաքագրում և ճանապարհային հատվածների հետ համապատասխանեցում։
6. Տվյալների մշակում և GNN մոդելի ուսուցում։
7. Կանխատեսված անցման ժամանակների հիման վրա դինամիկ երթուղու որոնում։

A* ալգորիթմի հեվրիստիկան պետք է լինի ընդունելի (admissible), այսինքն՝ չգերագնահատի նպատակակետին հասնելու իրական նվազագույն արժեքը։
