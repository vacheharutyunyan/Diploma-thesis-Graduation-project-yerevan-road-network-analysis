# Օգտագործվող աղբյուրներ

- OpenStreetMap — ճանապարհային ցանցի աշխարհագրական տվյալներ։
- OSMnx documentation — ճանապարհային ցանցերի ներբեռնում և վերլուծություն։
- NetworkX documentation — գրաֆային ալգորիթմներ։
- Գիտական հոդվածներ՝ Graph Neural Networks և traffic forecasting թեմաներով։

Յուրաքանչյուր օգտագործված տվյալաշարի և գիտական աղբյուրի ամբողջական հղումը պետք է ավելացվի այստեղ։
